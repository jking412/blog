## 重新执行

在项目根目录安装依赖后运行：

```powershell
node scripts/migrate-hexo.mjs 'D:\blog\source\_posts'
node scripts/verify-content.mjs 'D:\blog\source\_posts'
```

迁移脚本会在写入前检查全部目标路径，完全相同的文件允许重复执行；目标内容不同会报冲突并停止，不会覆盖已编辑的文章。若新增旧站文章，可以直接重复运行。若旧站已有文章发生修改，应先审阅源与目标的差异，再明确处理目标冲突。

迁移源路径作为命令行第一个参数传入。没有源目录时，也可以独立检查仓库文章：

```powershell
node scripts/verify-content.mjs
```

验证脚本检查 frontmatter 字段、日期、标签与分类类型、唯一旧路径、未转换的文章链接和本地图片存在性。提供源路径时，额外重建迁移结果并逐篇比较正文及元数据，确认迁移没有遗漏或截断。
